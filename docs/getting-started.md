# Getting started with PAI

Private AI on a bootable USB drive. Your secure, offline-first AI assistant — carry it anywhere, leave no trace.

## Install

```bash
git clone https://github.com/nirholas/PAI.git
```

## Verify the install

Clone the repository and run its checks to confirm everything works on your machine:

```bash
git clone https://github.com/nirholas/PAI.git
cd PAI
```
